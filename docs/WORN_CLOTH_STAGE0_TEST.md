# Надетая одежда, этап 0 — проверка в игре

План: [WORN_CLOTH_PLAN.md](WORN_CLOTH_PLAN.md), §5 «Этап 0». Цель — убедиться, что подход «подменяем матрицы костей в
палитре вещи» работает, и снять данные о костях и системах координат. Ничего из этого не видно игроку, пока не включён
пробник: по умолчанию всё выключено.

## Подготовка

1. Собрать и задеплоить мод: `gradlew :pz-adapter:deployMod` (уже сделано на момент написания).
2. Сгенерировать локальный тестовый мод с моделями (ванильный длинный плащ, у которого передний подол привязан к
   костям `FF_TestFront*`, которых нет в скелете):

   ```
   py tools/make_test_garment.py
   ```

   Он создаёт `%USERPROFILE%\Zomboid\mods\FloppyFabricsGarmentTest` (в репозиторий и в Workshop не попадает).
3. В игре: в списке модов включить **Floppy Fabrics** и **Floppy Fabrics - garment test (local)**. Запустить с `-debug`.
4. Новая игра (или сохранение), надеть **халат** (`Base.LongCoat_Bathrobe`, в debug-меню предметов: Clothing → Bathrobe).
   Для проверки на женском теле — тот же халат на женском персонаже.

Все команды вводятся в Lua-консоль (F11 → Lua Console). Ответы и подробности пишутся в `console.txt` со строками
`[FloppyFabrics] garment …`.

## Проверка 1. Подмена матрицы доходит до экрана

```lua
FloppyFabrics_garmentProbe(true)
FloppyFabrics_garmentTilt(35, 2)
```

**Ожидание:** передний подол халата заметно отклонён (вперёд или вбок, это зависит от оси). Если отклонения не видно,
попробовать оси `0` и `1`: `FloppyFabrics_garmentTilt(35, 0)`, `FloppyFabrics_garmentTilt(35, 1)`. Записать, какая ось
поднимает подол **вперёд**.

Там же проверить:
- **Ходьба и бег**: отклонение держится и движется вместе с персонажем, без дрожания.
- **Контур**: навести курсор на зомби в длинной одежде (плащ, пончо, свадебное платье, фартук) с оружием в руках — красный
  контур повторяет отклонённый подол.
- **Толпа**: найти несколько зомби в такой одежде рядом, у всех подол отклонён. Это путь с инстансингом.
- **Превью в инвентаре** (3D-модель персонажа в окне персонажа): ошибок в консоли нет.

Выключить: `FloppyFabrics_garmentTilt(0, 0)`.

## Проверка 2. Кости моделей

```lua
FloppyFabrics_garmentDump()
```

**Ожидание:** в `console.txt` есть строки `garment dump: …` и по строке на каждую модель (`bones=`, `skeleton=`,
`extras=`) плюс строки `bone …` с позициями и осями для `Bip01`, `Bip01_Pelvis`, `Bip01_Head`, `Bip01_L_Foot`,
`Bip01_DressFront`… Пробник при включении также один раз логирует каждую новую модель (`garment probe: model …`).

Записать:
- `skeleton=` (размер скелета) и `bones=` у тела и у халата — сколько слотов остаётся до 60.
- По строкам `bone`: какая ось вверх (голова выше ног), какая вперёд, масштаб (`scale=`: 1 или 0,01). Повторить дамп,
  повернувшись на 90°, и сравнить `renderedAngle` и позиции: так видно, вращаются ли кости вместе с персонажем в model space.

## Проверка 3. Кости только из файла модели (`FF_*`)

```lua
FloppyFabrics_garmentSwap("LongCoat_Bathrobe", "skinned\\clothes\\ff_test_longcoat_bob|skinned\\clothes\\ff_test_longcoat_kate")
FloppyFabrics_garmentDump()
```

**Ожидание:** в консоли строка `garment probe: model swap live, LongCoat_Bathrobe: … -> …`. В дампе у тестовой модели
`extras=[FF_TestFront#.. <- Bip01_Pelvis, FF_TestFront02#.. <- FF_TestFront, …]`. Халат выглядит как обычно, потому что
режим по умолчанию — `2` (FF-кости повторяют ванильные Dress-кости).

Затем по очереди:

| Команда | Ожидание |
|---|---|
| `FloppyFabrics_garmentFF(0)` | Передний подол «застывает» в позе привязки (T-поза): при ходьбе, приседании и беге перед халата не следует за ногами, может торчать или провалиться в тело. Так ведут себя кости, которые игра не заполняет. |
| `FloppyFabrics_garmentFF(1)` | Передний подол жёстко идёт за тазом (без анимации подола), но уже не застывает. |
| `FloppyFabrics_garmentFF(2)` | Снова как ванильный халат. |
| `FloppyFabrics_garmentTilt(35, <ось из проверки 1>)` | Отклоняется и передний подол тестовой модели (кости `FF_TestFront*`). |

Вернуть всё как было:

```lua
FloppyFabrics_garmentTilt(0, 0)
FloppyFabrics_garmentSwap("LongCoat_Bathrobe", "")
FloppyFabrics_garmentProbe(false)
```

## Проверка 4. Ошибки

```lua
FloppyFabrics_garmentStatus()
```

**Ожидание:** `failed=false hookSeen=true`, `calls` растёт, `touched` > 0 во время наклона. В `console.txt` нет строк
`[FloppyFabrics] WARN garment probe failed`. Если ZombieBuddy не смог применить патч, при старте будет ошибка про
`AnimatedModel$AnimatedModelInstanceRenderData` или `ClothingItem.getModel`, а `hookSeen` останется `false`.

## Что прислать

- Скриншоты: подол с наклоном (свой персонаж и толпа), контур, `FF(0)` с застывшим подолом.
- Строки `console.txt`, содержащие `garment`.
- Какая ось наклоняет подол вперёд, и всё, что выглядело неправильно.
